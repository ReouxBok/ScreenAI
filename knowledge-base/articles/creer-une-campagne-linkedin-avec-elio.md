# Créer une Campagne LinkedIn avec Elio

## 📧 Campagne de Prospection LinkedIn

### L'essentiel
Automatisez vos demandes de connexion LinkedIn et messages de suivi avec personnalisation avancée.
&nbsp;

### 🚀 Comment créer une campagne ?

&nbsp;&nbsp;******Méthode rapide :******

- ******Super Pouvoirs******&nbsp;&gt;&nbsp;******Campagne de Prospection LinkedIn******
- Configurez :
- 
- ******Nom******&nbsp;: "Prospection CMOs Tech Q1 2026"
- ******Mode******&nbsp;: Connexion simple, avec message, ou message direct
- ******Message******&nbsp;: Utilisez {{Prénom}}, {{Nom}}, {{Entreprise}}, {{Poste}}
- ******Prospects******&nbsp;: Importez votre liste
- Lancez la campagne
### 🎯 Types de campagnes

&nbsp;&nbsp;******1. Invitation à se connecter******

- Demande de connexion sans message
- Idéal pour élargir rapidement le réseau
&nbsp;&nbsp;******2. Invitation à se connecter avec un message******
- Demande + message personnalisé (max 200 caractères)
- Idéal pour prospection qualifiée
&nbsp;&nbsp;******3. Envoyer un message******
- Message aux connexions 1er degré uniquement
- Idéal pour relance de contacts existants
&nbsp;
