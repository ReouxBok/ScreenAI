# Ajoutez vos Documents

# Ajoutez vos Documents

## 📄 Comment utiliser la page Documents ?

### L'essentiel
La page&nbsp;******Documents******&nbsp;vous permet d'uploader des fichiers pour que Charly et les agents puissent les lire, analyser et utiliser dans leurs réponses.
&nbsp;

### 🚀 Accéder à vos documents

&nbsp;&nbsp;******Étape simple :******

- Dans votre interface Limova
- Cliquez sur&nbsp;******Documents******&nbsp;dans le menu de gauche
- Vous voyez tous vos fichiers uploadés
&nbsp;
### 📤 Uploader un document

&nbsp;&nbsp;******Méthode 1 : Glisser-déposer******

- Ouvrez la page&nbsp;******Documents******
- ******Glissez-déposez******&nbsp;votre fichier dans la zone prévue
- Le fichier s'uploade automatiquement ✅
&nbsp;&nbsp;******Méthode 2 : Bouton Upload******
- Cliquez sur&nbsp;******Uploader un fichier******&nbsp;ou&nbsp;******+ Ajouter******
- Sélectionnez votre fichier sur votre ordinateur
- Validez
&nbsp;
### 📋 Formats acceptés

&nbsp;&nbsp;******Fichiers compatibles :******

- 📄 PDF
- 📝 Word (DOC, DOCX)
- 📊 Excel (XLS, XLSX)
- 📃 Texte (TXT)
- 📑 PowerPoint (PPT, PPTX)
&nbsp;&nbsp;******Taille maximale :******&nbsp;Généralement jusqu'à 50 MB par fichier
&nbsp;
### 💬 Utiliser vos documents avec Charly

&nbsp;******&nbsp;Une fois uploadés, vos documents sont accessibles à Charly :******
******&nbsp;&nbsp;Vous pouvez :******

- Définir un dossier comme ******contexte par défaut****** pour toutes vos conversations
- ******Démarrer une discussion****** depuis un dossier ou un document

&nbsp;

### 🗂️ Organiser vos documents

&nbsp;&nbsp;******Créer des dossiers :******

- Cliquez sur&nbsp;******Nouveau dossier******&nbsp;ou&nbsp;******+ Dossier******
- Nommez votre dossier (ex: "Contrats 2026", "Factures", "Rapports")
- Glissez-déposez vos fichiers dans les dossiers
&nbsp;&nbsp;******Avantages :******
- 📁 Organisation claire
- 🔍 Recherche plus facile
- 🎯 Catégorisation par projet/client/type
&nbsp;
### 🔍 Rechercher un document

&nbsp;&nbsp;******Barre de recherche :******

- En haut de la page Documents
- Tapez le nom du fichier ou mot-clé
- Résultats instantanés
&nbsp;&nbsp;******Filtres :******
- Par type de fichier (PDF, Word, etc.)
- Par date d'upload
- Par dossier
&nbsp;
### 🗑️ Gérer vos documents

&nbsp;&nbsp;******Actions disponibles :******
&nbsp;&nbsp;******Renommer :******

- Cliquez sur le fichier →&nbsp;******Renommer******
- Changez le nom →&nbsp;******Enregistrer******
&nbsp;&nbsp;******Télécharger :******
- Cliquez sur le fichier →&nbsp;******Télécharger******
- Le fichier se télécharge sur votre ordinateur
&nbsp;&nbsp;******Supprimer :******
- Cliquez sur le fichier →&nbsp;******Supprimer******
- Confirmez la suppression
&nbsp;&nbsp;******Déplacer :******
- Glissez-déposez le fichier dans un autre dossier
- Ou : Cliquez →&nbsp;******Déplacer vers******&nbsp;→ Sélectionnez le dossier
&nbsp;
### 🔒 Sécurité et confidentialité

&nbsp;&nbsp;******Vos documents sont sécurisés :******

- 🔐 Chiffrés lors du stockage
- 👤 Accessibles uniquement par vous et vos collaborateurs autorisés
- 🚫 Jamais partagés avec d'autres utilisateurs Limova
- 🗑️ Supprimables à tout moment
&nbsp;
### ⚠️ Bonnes pratiques

&nbsp;&nbsp;******À faire :******

- ✅ Nommez clairement vos fichiers (ex: "Contrat_Client_Dupont_2026.pdf")
- ✅ Organisez en dossiers par projet/client
- ✅ Supprimez les documents obsolètes régulièrement
- ✅ Uploadez des fichiers de qualité (texte lisible, pas de scan flou)
&nbsp;&nbsp;******À éviter :******
- ❌ Noms de fichiers vagues ("Document1.pdf", "Sans titre.docx")
- ❌ Tout mettre en vrac sans organisation
- ❌ Garder des fichiers inutiles
- ❌ Fichiers corrompus ou illisibles
&nbsp;
