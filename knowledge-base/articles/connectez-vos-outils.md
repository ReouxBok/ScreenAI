# Connectez vos Outils

## 🔌 Connecter vos premiers outils

### Pourquoi connecter vos outils ?
Pour que Charly et les agents puissent agir sur vos emails, calendrier, CRM, etc.
&nbsp;

### ✅ Outils essentiels à connecter en premier

&nbsp;&nbsp;******Communication &amp; Productivité :******

- ******Gmail******&nbsp;ou&nbsp;******Outlook******&nbsp;: Pour gérer vos emails
- ******Google Calendar******&nbsp;ou&nbsp;******Outlook Calendar******&nbsp;: Pour vos réunions
- ******Slack******&nbsp;ou&nbsp;******Teams******&nbsp;: Pour vos messages d'équipe
&nbsp;&nbsp;******CRM &amp; Contacts :******
- ******HubSpot******&nbsp;ou&nbsp;******Pipedrive******&nbsp;: Pour gérer vos clients
- ******Google Contacts******&nbsp;: Pour votre carnet d'adresses
&nbsp;&nbsp;******Stockage :******
- ******Google Drive******&nbsp;ou&nbsp;******OneDrive******&nbsp;: Pour vos documents
&nbsp;
### 🚀 Comment connecter un outil ?

******Via Intégrations******

- Allez dans&nbsp;******Intégrations******
- Trouvez l'outil (ex: Gmail)
- Cliquez sur&nbsp;******Connecter******
- Connectez-vous avec vos identifiants
- Autorisez les permissions
- C'est fait ✅

&nbsp;
### 🔐 Sécurité

- ******OAuth 2.0******&nbsp;: Protocole sécurisé standard
- ******Pas de stockage de mots de passe******&nbsp;: Limova ne connaît jamais vos identifiants
- ******Révocable******&nbsp;: Déconnectez à tout moment
&nbsp;
### ⚠️ Problème de connexion ?

- Rendez-vous dans la section ******Intégrations****** de votre interface. Vous y verrez toutes les connexions actives.
- Vérifiez que vous avez&nbsp;******autorisé toutes les permissions******
- ******Reconnectez******&nbsp;l'outil (déconnexion puis reconnexion)
- Vérifiez que votre compte tiers est&nbsp;******actif******
- Contactez le support si le problème persiste
&nbsp;

Si une intégration ne foncitionne pas, il est possible qu'elle existe mais qu'elle ne soit pas encore intégrée à Limova.
