# Générer une Image avec John

******1- 🎨 Comment générer des images directement dans le chat ?******

Si vous souhaitez créer des images ou vidéos directement dans la conversation :

⚠️ ******Important ******: La génération ne se fait pas dans le chat

La création d'images et de vidéos n'est ******pas disponible directement dans la conversation****** avec les agents.

✅ Procédure correcte

1. Accédez à l'onglet ******Super Pouvoirs****** dans votre interface Limova
2. Sélectionnez la fonctionnalité de génération d'images ou de vidéos
3. Lancez votre création depuis cet espace dédié

&gt; 💡 Astuce : L'onglet Super Pouvoirs centralise toutes les fonctionnalités avancées de création de contenu multimédia.

---

******2-🎬 Génération de vidéos******

La même règle s'applique pour les vidéos :

******- Pas de génération dans le chat******
******- Accès via Super Pouvoirs uniquement******

Cette organisation permet de bénéficier d'une interface optimisée pour la création de contenus visuels et vidéos.
