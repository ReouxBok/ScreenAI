# Générer une Vidéo avec John

******1-🎬 Comment générer des vidéos avec John ?******

Si vous souhaitez créer des vidéos directement dans le chat, voici la procédure à suivre :

⚠️ Important : La génération ne se fait pas dans le chat

La création de vidéos n'est ******pas disponible directement dans la conversation****** avec John.

✅ Procédure correcte :

1. Accédez à l'onglet ******Super Pouvoirs****** dans votre interface Limova
2. Sélectionnez la fonctionnalité de génération de vidéos
3. Lancez votre création depuis cet espace dédié

&gt; 💡 ******Astuce****** : L'onglet Super Pouvoirs centralise toutes les fonctionnalités avancées de création de contenu.
