# Créer son Charly+

📱 ******Comment se connecter à Charly+ sur WhatsApp ?******

Installation rapide

Charly+ est la version WhatsApp de votre assistante Limova, disponible pour les utilisateurs de l'abonnement Business+. Installez-la en 3 étapes.

✅ Étape 1 : Enregistrez votre numéro

1. Connectez-vous à votre compte Limova

2. Allez dans ******Paramètres &gt; Entreprise******

3. Trouvez la section ******Numéro de Téléphone******

4. Entrez et ******enregistrez ******votre numéro personnel

5 .Allez dans ******Mon compte******

6. Entrez et ******enregistrez ******également votre numéro dans cette section

✅ Étape 2 : Ajoutez dans WhatsApp

1. Ouvrez ******Votre application contacts****** sur votre téléphone

2. Créez un ******nouveau contact****** avec le numéro : +33 7 56 95 75 09

3. Nommez-le "Charly+ Limova" (ou autre)

4. Enregistrez le contact

✅ Étape 3 : Démarrez la conversation

1. Ouvrez WhatsApp

2. Recherchez "Charly+"

3. Envoyez un message : ***"Bonjour"***

4. Charly+ vous répond ! ✅

Commande utile : ******/clear****** 

Cela réinitialise la conversation en cas de bug ou surcharge.

💡 ******Ce que Charly+ peut faire******

- ✅ Répondre à vos questions

- ✅ Rédiger des textes, emails

- ✅ Vous conseiller et guider

- ✅ Rechercher des informations sur le web

- ✅ Vous orienter vers les autres agents Limova

******Limitations :******

- ❌ Pas d'accès aux Super Pouvoirs

- ❌ Pour ces fonctionnalités, utilisez Charly sur l'interface web

🔄 Problème de connexion ?

******Charly+ ne répond pas ou dit qu'elle n'est pas connectée :******

1. Vérifiez que vous avez plusieurs ******workspaces******

2. Contactez le support avec le nom de votre workspace actif

3. L'équipe connectera Charly+ au bon workspace
