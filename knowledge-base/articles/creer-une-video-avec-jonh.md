# Créer une Vidéo avec Jonh

## 🎬 Génération de Vidéos

### L'essentiel
Créez des vidéos à partir de texte ou animez vos images. Max 8 secondes par clip.
&nbsp;

### 🚀 Comment générer une vidéo ?

&nbsp;&nbsp;******Méthode rapide :******

- ******Super Pouvoirs******&nbsp;&gt;&nbsp;******Génération de Vidéos******
- Choisissez le mode :
- 
- ******Texte → Vidéo******&nbsp;: Décrivez la vidéo
- ******Image → Vidéo******&nbsp;: Uploadez une image à animer
- Configurez :
- 
- Durée
- Format (16:9, 9:16, 1:1)
- Style (cinématique, animation, réaliste)
- Avec ou sans audio
- Générez
- Téléchargez (MP4)
### ✨ Options disponibles

&nbsp;&nbsp;******Modes :******

- 📝 Texte → Vidéo (description textuelle)
- 🖼️ Image → Vidéo (animation d'image)
&nbsp;&nbsp;******Personnalisation :******
- ⏱️ Durée
- 📐 Format : 16:9, 9:16, 1:1
- 🎨 Style : Cinématique, Animation, Réaliste, Artistique
- 🔊 Audio synchronisé (optionnel)
&nbsp;
### ⚠️ Limitations

- ⏱️&nbsp;******Max 8 secondes******&nbsp;par clip
- 🎬 Pour vidéos longues : générez plusieurs clips
&nbsp;
### 💡 Idéal pour

- 📱 Contenu réseaux sociaux
- 🛍️ Démos produits
- 📢 Vidéos marketing courtes
- 🎨 Animations d'images statiques
- 🎬 Prototypes et storyboards
&nbsp;
### 🔴 Erreur de génération ?

- Réessayez après 17h
- Simplifiez votre prompt
- Réduisez la durée
