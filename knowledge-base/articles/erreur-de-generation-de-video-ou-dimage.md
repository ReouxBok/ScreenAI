# Erreur de Génération de Vidéo ou d&#x27;Image

## Erreur lors de la génération de vidéo/image

### Le problème
Vous essayez de générer une vidéo ou une image, et vous obtenez une erreur.
&nbsp;

### ✅ Solutions

&nbsp;&nbsp;******1. Cela provient sûrement de votre capacité quotidienne******

- La génération de vidéos est ******limitée à une capacité journalière****** pour garantir sa disponibilité pour tous nos utilisateurs
- Le moteur se réinitialise****** chaque jour vers 17h******
- Si vous voyez une erreur, le moteur est probablement bloqué
&nbsp;&nbsp;******2. Réessayez après 17h******
- Attendez la réinitialisation (vers 17h)
- Ou réessayez le lendemain matin
&nbsp;&nbsp;******3. Réduisez le nombre d'images******
Pour les articles de blog :
- Si vous demandez 10 images, réduisez à 3-5
- Ou créez l'article sans images et ajoutez-les manuellement
&nbsp;&nbsp;******4. Simplifiez votre demande******
Pour les vidéos :
- Réduisez la durée (4 secondes au lieu de 8)
- Simplifiez votre description
- Réessayez avec un prompt plus court
