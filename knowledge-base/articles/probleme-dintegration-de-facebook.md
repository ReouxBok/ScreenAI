# Problème d'Intégration de Facebook

# Problème d&#x27;Intégration de Facebook

## 📘 Problème avec les pages Facebook

### Le problème
Vous rencontrez des difficultés avec vos pages Facebook :

- Pages non visibles dans Limova
- Impossible de publier sur vos pages
- Pages manquantes après connexion
- Erreurs lors de la publication
&nbsp;
### ✅ Solution : Reconnexion avec permissions complètes

&nbsp;&nbsp;******Procédure en 5 étapes :******
&nbsp;

### 1. Déconnectez Facebook

- Allez dans&nbsp;******Intégrations******
- Puis&nbsp;******Comptes connectés******
- Trouvez&nbsp;******Facebook******&nbsp;(pas "Facebook Page", uniquement "Facebook")
- Cliquez sur&nbsp;******Déconnecter******
&nbsp;
⚠️&nbsp;******Important :******&nbsp;Ne déconnectez que&nbsp;******Facebook******, pas "Facebook Page"
&nbsp;
### 2. Reconnectez Facebook

- Revenez sur&nbsp;******Intégrations******
- Trouvez&nbsp;******Facebook******
- Cliquez sur&nbsp;******Connecter Facebook******
&nbsp;
### 3. Paramètres avancés (CRUCIAL)

&nbsp;&nbsp;******Avant de valider la connexion :******

- Sur l'écran de connexion Facebook, cherchez&nbsp;******Paramètres avancés******
- Cliquez sur&nbsp;******Paramètres avancés******
&nbsp;
### 4. Sélectionnez toutes les pages

&nbsp;&nbsp;******Dans les paramètres avancés :******

- Trouvez l'option de sélection des pages
- ******Choisissez la première option :******
- 
- ✅&nbsp;******"Sélectionner tous ces éléments et les éléments futurs"******
&nbsp;
⚠️&nbsp;******Ne choisissez PAS******&nbsp;: "Sélectionner manuellement" ou "Pages spécifiques uniquement"
&nbsp;
### 5. Validez la connexion

- Autorisez toutes les permissions demandées
- Validez la connexion
- Vérifiez que le statut passe à&nbsp;******Connecté******&nbsp;✅
&nbsp;
### 🎯 Résultat

&nbsp;&nbsp;******Après cette procédure :******

- ✅ Toutes vos pages Facebook sont visibles dans Limova
- ✅ Les pages futures seront automatiquement ajoutées
- ✅ Publication fonctionne sur toutes les pages
- ✅ Plus d'erreurs de permissions
&nbsp;
