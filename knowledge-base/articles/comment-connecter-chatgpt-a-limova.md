# Comment connecter ChatGPT à Limova ?

# Comment connecter ChatGPT à Limova ?

## 🤖 Comment connecter OpenAI/ChatGPT à Limova ?

### Prérequis

⚠️&nbsp;******Important :******&nbsp;Vous devez avoir un&nbsp;******compte OpenAI Pro******&nbsp;(compte payant avec accès API).
&nbsp;
Les comptes gratuits ChatGPT ne donnent pas accès aux clés API.
&nbsp;

### 🚀 Étapes de connexion

&nbsp;&nbsp;******1. Générez votre clé API OpenAI******
&nbsp;

- Allez sur&nbsp;******platform.openai.com/api-keys******
- Connectez-vous avec votre compte OpenAI Pro
- Cliquez sur&nbsp;******Create new secret key******&nbsp;ou&nbsp;******+ Create new key******
- Donnez un nom à votre clé (ex: "Limova Integration")
- ******Copiez la clé immédiatement******&nbsp;(elle ne sera plus visible après)
- Format de la clé : sk-proj-xxxxxxxxxx
&nbsp;
⚠️&nbsp;******Attention :******&nbsp;Copiez bien la clé complète, vous ne pourrez plus la voir après avoir fermé la fenêtre.
&nbsp;&nbsp;******2. Connectez dans Limova******
&nbsp;
- Allez dans&nbsp;******Intégrations******
- Recherchez&nbsp;******ChatGPT******&nbsp;ou&nbsp;******OpenAI******
- Cliquez sur&nbsp;******Connecter******
- ******Collez votre clé API******&nbsp;dans le champ correspondant
- Cliquez sur&nbsp;******Valider******&nbsp;ou&nbsp;******Connecter******
- Statut passe à&nbsp;******Connecté******&nbsp;✅
&nbsp;
### ✅ Vérification

&nbsp;&nbsp;******Pour vérifier que la connexion fonctionne :******
&nbsp;

- Allez dans&nbsp;******Intégrations******
- Vérifiez que OpenAI/ChatGPT affiche&nbsp;******Connecté******&nbsp;✅
- Testez avec Charly :&nbsp;***"Utilise OpenAI pour me répondre"***
&nbsp;
### 🔧 Fonctionnement technique

&nbsp;&nbsp;******Intégration via Pipedream :******
&nbsp;
Cette intégration fonctionne via&nbsp;******Pipedream******, comme toutes nos autres intégrations (Gmail, Calendar, etc.).
&nbsp;&nbsp;******Important à savoir :******

- ✅ Limova utilise Pipedream comme plateforme d'intégration
- ⚠️ Les dysfonctionnements provenant de&nbsp;******Pipedream******&nbsp;ne dépendent pas de Limova
- 🔧 Si problème Pipedream : Nous ne pouvons pas intervenir directement
&nbsp;&nbsp;******En cas de dysfonctionnement Pipedream :******
- Le problème est du côté de l'infrastructure Pipedream
- Limova ne peut pas résoudre ces problèmes techniques
- Généralement résolu rapidement par Pipedream
&nbsp;
### 💡 Utilisation après connexion

&nbsp;&nbsp;******Une fois connecté, vous pouvez :******

- 🤖 Utiliser les modèles OpenAI dans vos workflows
- 🔧 Créer des automatisations avec GPT
- 🎯 Intégrer ChatGPT dans vos processus
- 📊 Utiliser l'API OpenAI via Limova
&nbsp;
### ⚠️ Problèmes fréquents

&nbsp;&nbsp;******"Clé API invalide"******
&nbsp;&nbsp;******Solutions :******

- ✅ Vérifiez que vous avez copié la clé&nbsp;******complète******&nbsp;(commence par sk-proj-)
- ✅ Vérifiez que votre compte OpenAI est&nbsp;******Pro******&nbsp;(pas gratuit)
- ✅ Vérifiez que la clé n'a pas été révoquée sur platform.openai.com
- ✅ Générez une nouvelle clé si nécessaire
&nbsp;&nbsp;******"Connexion échoue"******
&nbsp;&nbsp;******Solutions :******
- ✅ Vérifiez votre compte OpenAI sur platform.openai.com
- ✅ Vérifiez que vous avez des crédits API disponibles
- ✅ Reconnectez : Déconnectez puis reconnectez dans Intégrations
- ✅ Générez une nouvelle clé API
&nbsp;&nbsp;******"Erreur Pipedream"******
&nbsp;&nbsp;******Solutions :******
- ⏱️ Attendez quelques minutes (problème temporaire)
- 🔄 Réessayez plus tard
- 📞 Contactez le support si persiste (nous vérifierons le statut Pipedream)
&nbsp;
### 💰 Coûts OpenAI

&nbsp;&nbsp;******Important :******

- 💳 L'utilisation de l'API OpenAI est&nbsp;******facturée par OpenAI******&nbsp;directement
- 📊 Consultez vos coûts sur platform.openai.com
- 🔋 Assurez-vous d'avoir des crédits API disponibles
- ⚠️ Les coûts API sont&nbsp;******séparés******&nbsp;de votre abonnement Limova
&nbsp;
### 🔐 Sécurité

&nbsp;&nbsp;******Protection de votre clé API :******

- 🔒 Votre clé est stockée de manière sécurisée
- 🚫 Limova ne partage jamais votre clé
- ✅ Vous pouvez révoquer la clé à tout moment sur platform.openai.com
- 🔄 Changez régulièrement votre clé pour plus de sécurité
&nbsp;&nbsp;******Si vous pensez que votre clé a été compromise :******
- Allez sur platform.openai.com/api-keys
- Révoquez l'ancienne clé
- Générez une nouvelle clé
- Mettez à jour dans Limova (Intégrations &gt; OpenAI)
