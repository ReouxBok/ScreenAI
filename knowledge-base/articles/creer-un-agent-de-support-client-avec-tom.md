# Créer un Agent de Support Client avec Tom

## 💬 Créer un Chatbot de Support Client avec Tom

### L'essentiel
Créez un chatbot autonome pour votre site web ou service client avec IA conversationnelle, base de connaissances et transfert vers humain.
&nbsp;

### 🚀 Comment créer un chatbot de support ?

&nbsp;&nbsp;******Méthode rapide :******

- ******Super Pouvoirs******&nbsp;&gt;&nbsp;******Tom - Créer un agent de Support******
- Configurez votre chatbot :
- 
- ******Nom******&nbsp;: "Assistant Support [Votre Entreprise]"
- ******Instructions******&nbsp;: Rôle, ton, comportement (min 50 caractères)
- ******Base de connaissances******&nbsp;: Uploadez vos fichiers (max 20)
- ******Règles de transfert******&nbsp;: Quand passer à un humain

******Vous pouvez demander de l'aide à Tom pour créer un prompt efficace. Il est très recommandé de le faire.******

- Créez le chatbot
### 

### 📚 Base de connaissances (RAG)

&nbsp;&nbsp;******Uploadez vos documents (max 20 fichiers) :******

- 📄 FAQ de votre entreprise
- 📋 Guides d'utilisation produits
- 💰 Politique de prix et remboursements
- 📦 Informations livraison et retours
- 🔧 Guides de dépannage technique
- 📞 Coordonnées et horaires
&nbsp;
→ Le chatbot utilise ces fichiers pour répondre avec précision
&nbsp;&nbsp;******Formats acceptés :******
- PDF, DOC, DOCX, TXT
- Max 20 fichiers par chatbot
&nbsp;
### 🔄 Règles de transfert vers humain

&nbsp;&nbsp;******Configurez quand transférer à un conseiller humain :******
&nbsp;&nbsp;******1. Sur demande utilisateur (onUserRequest)******

- ✅ Activez : Le client peut demander un humain à tout moment
- Message : "Je vous transfère vers un conseiller..."
&nbsp;&nbsp;******2. Mots-clés détectés (onKeywordsDetected)******
- 🔑 Mots-clés : "remboursement", "réclamation", "urgent", "problème grave", "insatisfait"
- → Transfert automatique si ces mots sont prononcés
&nbsp;&nbsp;******3. Message personnalisé de transfert (handoffMessage)******

"Je vous transfère vers un conseiller humain 
qui pourra mieux vous aider avec cette demande. 
Un instant s'il vous plaît..." 

&nbsp;&nbsp;******Exemple de configuration :******

Règles de transfert :
- ✅ Transfert sur demande utilisateur
- 🔑 Mots-clés : "remboursement", "réclamation", "urgent", "parler à quelqu'un"
- 💬 Message : "Je vous mets en relation avec un conseiller..." 

&nbsp;

### 💡 Exemples par secteur

&nbsp;&nbsp;******E-commerce :******
Instructions : "Assistant support e-commerce. 
Aide sur commandes, livraisons, retours, produits." 

Base de connaissances :
- FAQ livraison
- Politique de retour
- Catalogue produits
- Guide des tailles 

Transfert si : "remboursement", "colis perdu", "réclamation" 

&nbsp;&nbsp;******SaaS/Tech :******
Instructions : "Assistant support technique. 
Aide sur fonctionnalités, bugs, compte utilisateur." 

Base de connaissances :
- Documentation produit
- Guides tutoriels
- FAQ technique
- Troubleshooting 

Transfert si : "bug critique", "ne fonctionne pas", "urgent" 

&nbsp;&nbsp;******Service professionnel :******
Instructions : "Assistant cabinet [profession]. 
Informations RDV, tarifs, services." 

Base de connaissances :
- Services proposés
- Tarifs
- Horaires
- Coordonnées 

Transfert si : "urgence", "rendez-vous", "devis"

### ✨ Fonctionnalités

&nbsp;&nbsp;******IA conversationnelle :******

- 💬 Comprend le langage naturel
- 🎯 Réponses contextuelles précises
- 📚 Utilise votre base de connaissances (RAG)
- 🔄 Gestion de conversations multi-tours
&nbsp;&nbsp;******Transfert intelligent :******
- 🤝 Transfert vers humain quand nécessaire
- 🔑 Détection de mots-clés critiques
- 👤 Demande utilisateur respectée
- 📝 Contexte transmis au conseiller
&nbsp;&nbsp;******Multilingue :******
- 🌍 Détection automatique de la langue
- 💬 Répond dans la langue du client
&nbsp;
### 🎯 Cas d'usage

&nbsp;&nbsp;******Support client 24/7 :******

- Réponses aux questions fréquentes
- Aide à la navigation
- Résolution problèmes simples
- Escalade vers humain si complexe
&nbsp;&nbsp;******Qualification de demandes :******
- Collecte d'informations
- Qualification du besoin
- Orientation vers bon service
- Prise de contact
&nbsp;&nbsp;******Réduction de charge support :******
- Traite 60-80% des questions simples
- Libère les conseillers pour cas complexes
- Disponible hors horaires
- Réponses instantanées
&nbsp;
### ⚠️ Bonnes pratiques

&nbsp;&nbsp;******À faire :******

- ✅ Base de connaissances complète et à jour
- ✅ Instructions claires (min 50 caractères)
- ✅ Règles de transfert bien définies
- ✅ Testez le chatbot avant déploiement
- ✅ Mettez à jour régulièrement les documents
&nbsp;&nbsp;******À éviter :******
- ❌ Base de connaissances incomplète
- ❌ Instructions trop vagues
- ❌ Pas de règle de transfert (client bloqué)
- ❌ Oublier de tester
