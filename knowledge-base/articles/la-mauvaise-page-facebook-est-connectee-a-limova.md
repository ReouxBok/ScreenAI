# La mauvaise page facebook est connectée à Limova

## 📘 La mauvaise page Facebook est connectée à Limova

### Le problème

&nbsp;
Vous avez connecté Facebook à Limova, mais ce n'est pas la bonne page qui apparaît, ou certaines pages sont manquantes.
&nbsp;

### ✅ Solution : Reconnecter avec les bonnes pages

&nbsp;&nbsp;******Procédure en 5 étapes :******
&nbsp;

### 1. Déconnectez Facebook

- Allez dans&nbsp;******Intégrations******
- Trouvez&nbsp;******Facebook******
- Cliquez sur&nbsp;******Déconnecter******
- Confirmez la déconnexion
&nbsp;
### 2. Relancez la connexion

- Restez dans&nbsp;******Intégrations******
- Trouvez&nbsp;******Facebook******
- Cliquez sur&nbsp;******Connecter******
&nbsp;
### 3. Modifier les paramètres (ÉTAPE CRUCIALE)

&nbsp;&nbsp;******Au moment où la plateforme Facebook demande si tous les paramètres sont OK :******

- ******Ne validez PAS immédiatement******
- Cherchez le bouton&nbsp;******Modifier les paramètres précédents******&nbsp;ou&nbsp;******Modifier******
- Cliquez dessus
&nbsp;
### 4. Sélectionnez vos pages

&nbsp;&nbsp;******Dans les paramètres de connexion :******

- Vous verrez la liste de toutes vos pages Facebook
- ******Cochez les pages qui vous intéressent******
- ******Recommandation :******&nbsp;Sélectionnez&nbsp;******TOUTES les pages******&nbsp;pour être sûr
&nbsp;&nbsp;******Pourquoi tout sélectionner ?******
- ✅ Évite d'oublier une page
- ✅ Les futures pages seront automatiquement incluses
- ✅ Plus besoin de reconnecter à chaque nouvelle page
&nbsp;
### 5. Validez la connexion

- Cliquez sur&nbsp;******Valider******&nbsp;ou&nbsp;******Continuer******
- Autorisez toutes les permissions demandées
- Vérifiez que le statut passe à&nbsp;******Connecté******&nbsp;✅
&nbsp;
### 🎯 Vérification

&nbsp;&nbsp;******Pour confirmer que les bonnes pages sont connectées :******

- Allez dans&nbsp;******Super Pouvoirs******&nbsp;&gt;&nbsp;******John - Création de Posts******
- Créez un nouveau post Facebook
- Dans le champ "Page Facebook", vérifiez que vos pages apparaissent
- Si toutes vos pages sont là → Connexion réussie ✅
&nbsp;
### 📷 Fonctionne aussi pour Instagram

&nbsp;&nbsp;******Cette procédure est identique pour Instagram :******

- ******Intégrations******&nbsp;&gt;&nbsp;******Instagram******&nbsp;&gt;&nbsp;******Déconnecter******
- ******Reconnecter******
- ******Modifier les paramètres précédents******
- ******Sélectionnez tous vos comptes Instagram******&nbsp;(recommandé)
- ******Validez******
&nbsp;
⚠️&nbsp;******Important pour Instagram :******&nbsp;Vous devez avoir des comptes&nbsp;******Instagram Business******&nbsp;ou&nbsp;******Instagram Creator******&nbsp;(pas de comptes personnels classiques).
&nbsp;
### 💡 Pourquoi ce problème arrive ?

&nbsp;&nbsp;******Raisons courantes :******

- ******Sélection partielle lors de la première connexion******
- 
- Vous n'aviez sélectionné que certaines pages
- Les autres pages n'ont pas été autorisées
&nbsp;
- ******Nouvelles pages créées après connexion******
- 
- Les nouvelles pages ne sont pas automatiquement ajoutées
- Il faut reconnecter pour les inclure
&nbsp;
- ******Changement de rôle sur les pages******
- 
- Vous n'étiez pas admin au moment de la connexion
- Maintenant vous êtes admin, mais la connexion ne le sait pas
&nbsp;
### ⚠️ Points d'attention

&nbsp;&nbsp;******Rôles requis :******

- ✅ Vous devez être&nbsp;******Administrateur******&nbsp;de la page Facebook
- ❌ Les rôles Éditeur ou Modérateur peuvent causer des problèmes
&nbsp;&nbsp;******Type de compte Instagram :******
- ✅ Compte&nbsp;******Instagram Business******&nbsp;ou&nbsp;******Creator******
- ❌ Compte personnel classique non supporté
&nbsp;&nbsp;******Pages vs Profil :******
- ✅ Limova se connecte aux&nbsp;******Pages Facebook******&nbsp;(professionnelles)
- ❌ Pas aux profils personnels Facebook
&nbsp;
### 🔄 Si le problème persiste

&nbsp;&nbsp;******Vérifications supplémentaires :******
&nbsp;

- ******Vérifiez vos rôles******
- 
- Allez sur facebook.com
- Paramètres de la page
- Vérifiez que vous êtes bien&nbsp;******Administrateur******
&nbsp;
- ******Vérifiez les restrictions******
- 
- Votre page a-t-elle des restrictions actives ?
- Connectez-vous sur business.facebook.com pour vérifier
&nbsp;
- ******Essayez avec un autre navigateur******
- 
- Parfois les cookies peuvent causer des problèmes
- Essayez en navigation privée
&nbsp;
- ******Attendez quelques minutes******
- 
- La synchronisation peut prendre 5-10 minutes
- Rafraîchissez la page Limova
&nbsp;
