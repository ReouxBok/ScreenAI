# Connaissances Studio

L’extension n’embarque aucune base de connaissances. Les contenus sont écrits, relus et publiés dans le Studio, puis exposés au Deep Agent principal par MCP. Un brouillon ou un contenu non publié ne doit pas être utilisable par Charly.

La qualification doit vérifier : l’isolation workspace, la version publiée, les citations ou identifiants de contenu attendus, l’invalidation après dépublication et l’absence de fallback local. Les démonstrations formateur complètent ces contenus avec des gestes observés sans enregistrer les valeurs de formulaire.
